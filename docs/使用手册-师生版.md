# ER-Think 使用手册（教师版 · 学生版）

适用：当前 Web 师生系统（Next.js）。验收主病例为 **STEMI #03**，另有 Demo 导入的多病种病例。

---

## 一、如何打开系统

1. 进入项目 `代码` 目录，确认已配置 `.env.local`（至少 `DATABASE_URL`、`SESSION_SECRET`）。
2. 首次或病例更新后执行：`npm run db:init`（或 `node scripts/run-init-from-env.mjs`）。
3. 启动：
   - 开发：`npm run dev`
   - 生产：`npm run build` → `npm start`
4. 浏览器打开：**http://localhost:5000**（或部署域名 / Coze 预览地址）。

未登录访问首页会跳到登录页；登录后按角色自动进入对应首页。

### 演示账号（初始化种子）

| 角色 | 用户名 | 密码 | 登录后首页 |
|------|--------|------|------------|
| 教师 | `teacher` | `Teacher123!` | 教学看板 |
| 学生 | `student1` | `Student123!` | 开始训练 |

登录页可一键填入上述账号。

## 二、教师版怎么用

顶栏：**教学看板** | **病例导入** | **学生管理**

### 1. 教学看板（日常主入口）

路径：`/dashboard`

用途：看班级训练进度与成绩。

操作建议：

1. 用 **状态**（进行中 / 已完成）、**结局 Path A–D**、**开始/结束日期** 筛选。
2. 看统计：筛选范围内的记录数、已完成数。
3. 在表格中查看：学生、病例、状态、总分、结局、开始时间。
4. 点 **详情** → 进入该次训练过程页（`/sessions?id=…`）：基本信息、六维得分条、决策记录、问诊覆盖、对话摘要。

说明：教师详情侧重过程抽查；雷达图 / 路径对照 / 逐节点评语 / 导出 Word，在学生复盘与「我的记录」里更完整。

### 2. 病例导入与发布

路径：`/cases`

用途：把病例 JSON 导入本租户，并控制学生是否可见。

操作建议：

1. 上传 JSON 或粘贴内容；需要时可勾选 **导入后立即对学生发布**。
2. 可用 **载入 STEMI 模板副本** 快速拿到标准结构。
3. 在「本租户病例」列表中 **发布 / 下架**：
   - **已发布**：学生选病例时可见、可练；
   - **下架**：学生看不到该病例。

初始化后，内置病例（含 `stemi-03` 等）一般为已发布状态。新导入病例请确认已发布再让学生开练。

### 3. 学生管理

路径：`/students`

用途：维护本班学生账号。

操作建议：

1. **新增**：用户名、显示名、学号、初始密码。
2. **编辑**：可改资料与密码。
3. **删除**：会一并清理该生训练记录，操作前请确认。

### 4. 教师推荐工作流（课堂上）

```
登录教师账号
  → 学生管理：建好本班账号
  → 病例导入：确认 stemi-03（或指定病例）已发布
  → 让学生登录开练
  → 看板筛选「进行中 / 已完成」巡课
  → 点详情抽查：是否按时 ECG、用药/策略、病情波动是否处置
  → 课后按结局 Path、总分讲评薄弱维度
```

## 三、学生版怎么用

顶栏：**开始训练** | **我的记录**

### 1. 选病例开练

路径：`/train`

1. 在列表中选择已发布病例（建议先练 **急诊胸痛评估 · 急性前壁 STEMI** / `stemi-03`）。
2. 若有未完成记录：可 **继续上次**，或 **重新开始**。
3. 点 **开始训练** 进入训练台。

### 2. 训练台怎么操作

左侧：

- **病例卡**：目标时长、模拟时钟 `T+分钟`、真实墙钟 `MM:SS`
- **病情波进度**：本例有多波波动/恶化，结束前需走完
- **六维能力**：实时累计分
- **知识点**：教学卡片（辅助，不代替操作）
- **结束演练并复盘**

主区上方：

- **生命体征监护**：随病情波动变黄/变红

三列：

| 区域 | 做什么 |
|------|--------|
| **问诊对话** | 上方快捷问句一点即问；也可手打发送。关键/安全信息会有标记 |
| **检查区** | **查体点选**：生命体征、心肺、双侧血压等逐项点开；再点检验/心电图等开立，等回报 |
| **决策节点 P1–P8** | 选节点写理由并提交。**P5** 可勾选药物；**P6** 可点选再灌注策略 |

其他：

- 右下角 **Toast**：得分、超时、病情变化提醒
- **继续观察（推进 8 分钟）**：推进模拟时钟，可能触发病情变化
- 出现 **病情波动/危急** 卡片时：先勾选处置再提交，才能继续问诊/决策

### 3. STEMI 建议操作顺序（对照验收）

1. **P1** 分诊：II 级急症 / 胸痛绿色通道  
2. **问诊** + **查体点选**（生命体征、心肺、双侧血压等）  
3. **10 分钟内** 开立 **心电图**（超时会警告并影响结局）  
4. 开立必要化验（如肌钙蛋白等，勿因等化验耽误再灌注决策）  
5. **P5** 勾选抗栓等核心药并提交  
6. **P6** 选择 **直接 PCI** 等推荐策略并提交  
7. 用「继续观察」或推进时钟，按提示处置各波病情变化（含休克等）  
8. 补全 **P2–P4、P7、P8** 等节点理由  
9. 点 **结束演练并复盘**

### 4. 看复盘与导出

结束演练后，同页出现 **复盘成绩单**：

- 总分 /100、结局 Path A–D  
- 六维雷达图  
- 标准路径 vs 你的路径  
- **逐节点复盘评语**（达标 / 待加强 + 依据）  
- 六维评语、建议、推荐强化模块  
- **导出复盘** → 下载 `ER-Think复盘.doc`

### 5. 我的记录

路径：`/history` → **查看** → `/history/detail?id=…`

可再次查看历史成绩、雷达、路径对照、节点评语；已完成记录可再次导出复盘。

### 6. 学生推荐工作流

```
登录学生账号
  → 开始训练 → 选 stemi-03 → 开始
  → 问诊快捷键 + 查体点选 + 早做心电图
  → P5 勾药、P6 选直接 PCI
  → 处置病情波动，走完所有波
  → 结束演练 → 看雷达/路径/节点评语 → 导出 Word
  → 我的记录里复习薄弱节点
```

## 五、常见问题

**学生看不到病例？**  
教师到「病例导入」确认该病例为 **已发布**。

**点不了问诊/决策？**  
先完成当前 **病情变化** 处置卡片。

**心电图超时？**  
尽量在模拟 `T+10` 前开立心电图；超时会 Toast 警告并影响评分/结局。

**结束不了？**  
本例若配置了多波病情变化，需处理完（或按规则走完）后再结束。

**教师想看完整复盘图？**  
可让学生导出 Word，或在教师机用学生账号打开该次「我的记录」详情（注意勿在课堂混用权限）。后续若需教师端直接展示雷达/节点评语，可再迭代。
